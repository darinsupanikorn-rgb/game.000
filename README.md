# PIXEL QUEST — ไทยผจญภัย 🐃

เกมแพลตฟอร์มเมอร์พิกเซล HTML5 เล่นบนเบราว์เซอร์ได้เลย ไม่ต้องติดตั้ง ไม่ต้อง build — ดับเบิลคลิก `index.html` แล้วกด ▶ เริ่มผจญภัย

Pixel platformer in HTML5. Just open `index.html` in a browser — no install, no build.

## วิธีเล่น / How to play

| ปุ่ม | ทำอะไร |
|:---|:---|
| ← → / A D | เดิน |
| Space (กดค้างโดดสูง, กดซ้ำกลางอากาศ = โดด 2 ชั้น) | กระโดด / Double jump |
| ↓ + เดิน (S ค้างแล้วเดิน) | สไลด์ / Slide |
| X / J | ฟันดาบปราบควาย / Sword slash |
| C / K | ยิงปืนกูประดิษฐ์ / Shoot |
| ยืนบนท่อเขียว + กด ↓ | เข้ามินิเกมรับเหรียญ → ข้ามด่าน / Pipe minigame → skip level |
| P / Esc | หยุดพัก · M ปิดเสียง · F เต็มจอ |

รองรับจอยเกม (Gamepad API + สั่น) / Gamepad supported with rumble.

## ด่าน / Levels

1. ด่าน 1 — ทุ่งผักกาด (บอสปูยักษ์ 🦀 HP 3)
2. หมู่บ้านทุ่งทอง — แวะพัก
3. ด่าน 2 — ปราสาทโบราณ (บอสปูยักษ์ 🦀 HP 3)
4. หมู่บ้านริมวัด — ก่อนรบ
5. ด่าน 3 — รังควายยักษ์ (บอสควายยักษ์ 🐃 HP 5)

ฆ่าบอสได้ 3 วิธี: เหยียบ / ฟันดาบ / ยิงปืน — ต้องปราบบอสก่อนแตะธงถึงจะผ่านด่านได้

## ไฟล์ / Files

| ไฟล์ | คืออะไร |
|:---|:---|
| `index.html` | หน้าเกม + HUD + แดชบอร์ด |
| `game.js` | ตรรกะเกมทั้งหมด (~1400 บรรทัด, วาดพิกเซลด้วย canvas ล้วน, เสียงสังเคราะห์ WebAudio ไม่ใช้ไฟล์) |
| `qa-harness.js` | ชุดเทส headless — รันตรรกะเกมจริงใน Node |

## รันเทส / Run tests

```bash
node --check game.js
node qa-harness.js
```

เล่นให้สนุก! 🎮
